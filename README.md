# Task Timer

ToDo List con temporizador hecho en Next.js, React y MongoDB.

## Funcionalidades

- Crear tareas.
- Iniciar una tarea.
- Finalizar una tarea.
- Eliminar tareas.
- Ver el tiempo trabajado en formato `mm:ss`.
- Guardar tareas, estado y tiempo en MongoDB.

## Tecnologias

- Next.js
- React
- TypeScript
- MongoDB
- Mongoose
- Bun

## Instalacion

```bash
bun install
```

## Variables de entorno

Crea un archivo `.env` con tu conexion de MongoDB:

```env
MONGODB_URI=tu_url_de_mongodb
```

## Ejecutar en local

```bash
bun run dev
```

Abre:

```txt
http://localhost:3000
```

## Build

```bash
bun run build
```
